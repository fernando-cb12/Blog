Blog Entry 2: Week 2

Like I mentioned in my previous entry, my big project is to improve and modernize an internal development tool used by my team. This week I coordinated with my mentor to implement a new state machine for the tool, which allows for a better logging and more efficient way to handle the different states of the tool. we look for improvements area and summarized all the states into lifecycles and refactored the application client for this new state machine.

Beside of this, I also worked in the implementation of a new feature for the tool, which allows to handle different settings and enviroments until we found out a bug in the development, where my mentor wasn't able to send requests to the backend, so we spent almost 3 days debugging the problem, we had a call with senior engineers and couldn't find the problem, we traced the problem to a specific low level function in a package that was being used but the real issue was that the port was being used by another process, but it wasn't shown in the terminal so it was a bit weird, also nobody could reproduce his bug. This took some time to find out but the good thing is that we implemented better logging for future debugging.

This week I also participated in a social impact activity where we gave 86 backpacks to children in need, this is something that I particularly do and enjoy a lot, so I was really happy to be part of this activity and spend more time with my team doing different things.
